# 한국사2 1차 정기시험 대비 앱

2026년 10월 13일(화) 한국사2 1차 정기시험(객관식 33문항) 대비용 공부 앱이에요.
범위: 주제 01~13, 17~19, II-01~02 (교과서 6~51·62~82쪽, 수활북 6~37·44~59·120쪽~)

## GitHub Pages에 올리기
1. GitHub에서 새 저장소를 만들어요 (예: `Hanguksa-App`, Public).
2. 이 폴더의 파일을 **폴더 구조 그대로** 올려요: `index.html`, `manifest.webmanifest`, `sw.js`, `icons/` 폴더.
3. Settings → Pages → Branch를 `main`, 폴더를 `/ (root)`로 두고 Save.
4. 1~2분 뒤 `https://아이디.github.io/Hanguksa-App/` 으로 열려요.
5. 폰에서 그 주소를 열고 "홈 화면에 추가"하면 앱처럼 쓸 수 있어요. 한 번 열어 두면 인터넷 없이도 돼요.

- 오답 노트(자동 저장), 빨간 시트로 가리는 주제별 암기 노트, 헷갈리는 쌍

## 문제 고치거나 더하기
`index.html` 안에서 `const TD = {` 를 찾으면 주제별 데이터가 있어요.
노트 줄의 `{{정답|분류}}` 부분이 자동으로 빈칸 문제가 돼요. 주제 11은 `const RECALL`, `const EXAM`에 따로 있어요.
고친 뒤 GitHub에 다시 올리면 돼요. 기록(오답 노트)은 기기에 저장돼서 업데이트해도 남아요.
